# Stalika — arguments à faire apparaître sur le site

Deux arguments **obligatoires**. La formulation ci-dessous est un premier jet, à réécrire ; le fond, lui, est fixé.

---

## 1. Du sur-mesure, pas un modèle rempli

**Le fond.** Un créateur de site par IA, ou un site monté seul à partir d'un modèle, coûte quelques euros : c'est ce que les prospects savent déjà faire eux-mêmes. Stalika doit se situer nettement au-dessus de ce niveau.

**Ce qui fait la différence :**
- **Un design créé pour le client**, pas un modèle recoloré.
- **La logique métier** que les outils à modèles ne savent pas faire. Exemple réel, Popec : réservation avec agenda, espace client avec courbes de progression, espace coach, contrat en PDF.
- **Les contrôles** : mentions légales, sécurité, référencement.
- **Le client possède son site.** Avec un outil à modèles, le site reste enfermé dans l'outil. Avec Stalika, le code lui appartient.

**Premier jet :**
> Pas de modèle rempli à la chaîne. Chaque site Stalika est dessiné et construit pour votre activité : votre image, vos parcours, vos fonctionnalités (réservation, espace client, documents…). Il est livré conforme (mentions légales, sécurité, référencement), et il vous appartient.

---

## 2. Le lien de relecture : modifier son site sans rien casser

**Le fond.** Le client reçoit un lien vers son site. Avec ce lien, il le relit et le corrige directement sur la page. Exemple réel, la Pizzeria des Allées : le lien `?relecture` (voir `docs/relecture.md` dans le dépôt de la pizzeria).

**Ce que le client peut faire avec le lien :**
- Réécrire les textes à l'endroit même où ils apparaissent.
- Garder ou supprimer chaque animation.
- Commenter une image ou n'importe quel bloc de la page.
- S'arrêter et reprendre plus tard : ses retours restent dans son navigateur.

**Ce qu'il ne faut pas promettre.** Le site en ligne ne change pas tant que les retours ne sont pas appliqués : le client **propose**, Julien **applique et publie**. Ne pas écrire « modifiez votre site vous-même en direct », ce serait faux.

**Premier jet :**
> Pas besoin de décrire vos corrections par e-mail. Vous recevez un lien vers votre site : vous réécrivez les textes à leur place, vous gardez ou retirez les animations, vous commentez les images. J'applique vos retours et je publie. Personne ne casse rien.

---

## À valider avant publication

- **« Le code vous appartient »** : à inscrire noir sur blanc dans les conditions de vente ou le contrat. Sinon, on ne l'écrit pas sur le site.
- **Popec comme référence** : vérifier que le client est d'accord pour être cité.
- **Pizzeria des Allées comme référence** : même vérification.
